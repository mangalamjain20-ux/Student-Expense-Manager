# Problem Statement

Managing daily expenses can be difficult for students because small expenses such as food, transportation, stationery, and other personal needs can add up over time.

Students may not always keep track of how much they spend or how much money is left from their budget. A simple expense management system can help students record their expenses and understand their spending.

## Scope

The Student Expense Manager is a Python-based console application.

The project focuses on:

* Recording student expenses
* Viewing saved expenses
* Searching for expenses
* Setting a spending budget
* Calculating total expenses
* Checking remaining budget
* Generating a basic expense report
* Saving expense data using a CSV file
* Validating user input

The project is designed as a simple prototype and can be improved with additional features in the future.

## Target Users

The main target users are:

* College students
* University students
* Students who want to track daily spending
* Beginners who want a simple expense management tool

## High-Level Features

### 1. Expense Management

Users can add new expenses and view previously saved expenses.

### 2. Budget Management

Users can set a budget and check whether their total expenses are within the budget.

### 3. Reports and Analytics

The application calculates total expenses and displays the remaining budget.

### 4. Search and Filter

Users can search for an expense by entering its name.

### 5. Data Storage

Expense information is stored in a CSV file so that saved expenses can be loaded when the application starts.

### 6. Input Validation

The application checks user input to prevent invalid amounts, negative budgets, and empty text fields.
